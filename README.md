## Get Started
To play the Modpack, follow the steps below:
1) Download & Install Prism Launcher from: [https://prismlauncher.org](https://prismlauncher.org)
### Inside Prism Launcher
1) Login to your Microsoft Account inside the Prism Launcher
2) Select: **Add Instance** -> **Import** -> **Browse** and select the .mrpack File from the Releases Page
